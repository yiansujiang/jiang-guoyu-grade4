國語四上 數位教學樂園｜保護版網站（JS 壓縮混淆 + 極小載入器，未使用 WASM）

【內容】index.html、L1.html～L12.html（極小載入器）＋ js 資料夾（13 支，內含編碼後的完整頁面）
【重新發布到 GitHub（網頁上傳法）】
1. 解壓縮這個 zip。
2. 打開 https://github.com/yiansujiang/jiang-guoyu-grade4 → Add file → Upload files。
3. 把 index.html、L1～L12.html，以及整個 js 資料夾一起拖進去（會覆蓋舊檔）。
4. Commit changes。等 1～2 分鐘後，用無痕視窗開 https://yiansujiang.github.io/jiang-guoyu-grade4/ 。

【重要限制】這是「提高閱讀成本」，不是加密。瀏覽器仍會還原完整頁面，
懂技術的人用開發者工具仍可取得內容；請勿在網頁放入任何金鑰或機密。
【原始可讀版本】請保留電腦裡《四年級國語互動教材》資料夾的原檔，之後改課文都從原檔改，再重新產生保護版。
